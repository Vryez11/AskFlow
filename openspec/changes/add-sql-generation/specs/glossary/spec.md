# Spec Delta

## Purpose

개발자가 사내 용어의 정의와 컬럼 설명을 설정 파일에 적어 두면, 운영팀이 쓰는 말로 요청해도 SQL 생성에 그 정의가 반영되게 한다. 목표와 수용 기준은 PRD F-002를 따른다.

## ADDED Requirements

### Requirement: 용어 사전 설정 파일 (F-002)

시스템은 용어 사전 파일에서 용어(이름, 정의)와 컬럼 설명(`table.column`과 설명)을 읽어야 한다(SHALL). 파일 경로는 설정으로 정한다. 파일은 앱을 시작할 때 한 번 읽고, 고친 내용은 앱을 다시 시작하면 다음 요청부터 반영되어야 한다(SHALL). 경로를 비우면 용어 사전 없이 시작한다. 경로의 파일이 없거나 형식이 잘못되면 앱은 시작하지 않고 파일 경로와 잘못된 항목을 알려야 한다(SHALL).

#### Scenario: 용어 정의 반영
- **WHEN** 용어 사전에 "순매출 = 결제 금액 − 환불 금액"이 있고 "이번 달 순매출"을 묻는다
- **THEN** LLM에 보낸 요청에 순매출의 정의가 있다

#### Scenario: 다시 시작하면 반영
- **WHEN** 용어 사전 파일에서 순매출의 정의를 고치고 앱을 다시 시작한다
- **THEN** 다음 요청부터 고친 정의가 LLM에 간다

#### Scenario: 용어 사전 없음
- **WHEN** 용어 사전 경로를 비우고 앱을 시작한다
- **THEN** 앱이 시작하고, LLM에 용어 정의 없이 요청한다

#### Scenario: 형식이 잘못된 파일
- **WHEN** 용어 사전 파일에 이름이 빈 용어가 있다
- **THEN** 앱은 시작하지 않고, 파일 경로와 그 항목을 알려 준다

#### Scenario: 허용하지 않은 테이블의 컬럼 설명
- **WHEN** 컬럼 설명에 허용 테이블이 아닌 테이블의 컬럼이 있다
- **THEN** 그 설명은 LLM에 보내지 않는다

### Requirement: 용어 사전 켜고 끄기 (F-002)

시스템은 생성 요청마다 용어 사전을 켜거나 끌 수 있어야 한다(SHALL). 끄면 용어 정의와 컬럼 설명을 모두 LLM에 보내지 않는다. 기본은 켬이다. 용어 사전 효과(H5)를 평가 세트로 재는 데 쓴다.

#### Scenario: 끄고 만들기
- **WHEN** 용어 사전을 끄고 "이번 달 순매출"을 묻는다
- **THEN** LLM에 보낸 요청에 용어 정의와 컬럼 설명이 없다

### Requirement: 홈의 용어 수 (F-002)

연결 상태 조회의 용어 수는 시작할 때 읽은 용어 사전의 용어 수여야 한다(SHALL).

#### Scenario: 용어 12개
- **WHEN** 용어 12개가 있는 용어 사전으로 앱을 시작하고 연결 상태를 조회한다
- **THEN** 용어 수는 12다
