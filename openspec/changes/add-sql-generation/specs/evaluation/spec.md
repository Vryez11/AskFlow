# Spec Delta

## Purpose

평가 세트를 자동으로 돌려 SQL 생성의 정답률을 기록하고, 용어 사전을 켠 상태와 끈 상태를 비교하며, 틀린 문항을 고칠 수 있게 실패 리포트를 남긴다. 목표는 PRD 2장의 H1, H5를 따른다.

## ADDED Requirements

### Requirement: 평가 세트 (F-002)

평가 세트는 Olist 질문 30개로 이루어져야 한다(SHALL). 문항마다 한국어 질문, 정답 SQL, 행 순서를 따지는지 여부를 둔다. 정답은 값이 아니라 SQL로 두어, 시드할 때마다 날짜가 옮겨져도 정답이 그대로 맞아야 한다(SHALL). 정답 SQL은 상대 기간을 DB의 오늘(`CURDATE()`) 기준으로 계산한다.

#### Scenario: 정답 SQL은 실행된다
- **WHEN** 시드한 Olist DB에서 평가 세트의 정답 SQL 30개를 안전 실행 경로로 실행한다
- **THEN** 모두 오류 없이 실행된다

### Requirement: 결과 비교 (F-002)

시스템은 생성 SQL과 정답 SQL을 같은 DB에서 실행해 결과로 정답을 판정해야 한다(SHALL). 열 이름과 열 순서는 보지 않고, 정답 결과의 열마다 같은 값을 가진 열이 생성 결과에 있으면 맞은 것으로 본다. 생성 결과에 열이 더 있어도 된다. 행 순서를 따지지 않는 문항은 행 순서를 무시한다. 숫자는 상대 오차 0.0001 안이면 같다고 본다. 생성이나 실행이 실패하면 틀린 것으로 본다(SHALL).

#### Scenario: SQL은 다르고 결과는 같음
- **WHEN** 생성 SQL이 정답 SQL과 문장은 다르지만 같은 결과를 낸다
- **THEN** 맞은 것으로 판정한다

#### Scenario: 열 이름과 순서가 다름
- **WHEN** 생성 결과의 열 이름과 순서가 정답과 다르고 값은 같다
- **THEN** 맞은 것으로 판정한다

#### Scenario: 정렬을 따지지 않는 문항
- **WHEN** 행 순서를 따지지 않는 문항에서 행 순서만 다르다
- **THEN** 맞은 것으로 판정한다

#### Scenario: 정렬을 따지는 문항
- **WHEN** 행 순서를 따지는 문항(예: "매출 상위 5개 카테고리")에서 행 순서가 다르다
- **THEN** 틀린 것으로 판정한다

#### Scenario: 값이 다름
- **WHEN** 생성 결과의 값이 정답과 다르다
- **THEN** 틀린 것으로 판정한다

#### Scenario: 생성 실패
- **WHEN** 생성이 끝까지 실패하거나 실행 오류가 난다
- **THEN** 틀린 것으로 판정하고 그 오류 종류를 남긴다

### Requirement: 정답률 기록 (F-002)

평가를 돌리면 시스템은 정답률, 문항별 판정, 용어 사전 켬·끔, 쓴 공급자와 모델, 실행 날짜를 남겨야 한다(SHALL). 정답률은 레포에 커밋하는 이력 파일에 한 줄씩 더해, 직전 기록과 비교할 수 있어야 한다(SHALL). 평가는 LLM 비용이 드니 CI에서 자동으로 돌리지 않는다.

#### Scenario: 이력에 한 줄 더함
- **WHEN** 용어 사전을 켜고 평가를 한 번 돌린다
- **THEN** 이력 파일에 날짜, 켬, 공급자와 모델, 맞은 수, 전체 수, 정답률 한 줄이 더해진다

### Requirement: 용어 사전 켬·끔 비교 (F-002)

시스템은 같은 평가 세트를 용어 사전을 켠 상태와 끈 상태로 각각 돌려, 두 정답률과 한쪽에서만 맞은 문항을 볼 수 있게 해야 한다(SHALL).

#### Scenario: 켬과 끔 비교
- **WHEN** 켬과 끔으로 각각 평가를 돌린다
- **THEN** 두 정답률과, 켬에서만 맞은 문항과 끔에서만 맞은 문항 목록이 나온다

### Requirement: 실패 리포트 (F-002)

시스템은 틀린 문항마다 질문, 정답 SQL과 결과, 생성 SQL과 결과 또는 오류, 가정, 시도 횟수를 나란히 보여 주는 리포트를 남겨야 한다(SHALL). 리포트는 결과 값을 담으므로 커밋하지 않는 폴더에 둔다.

#### Scenario: 틀린 문항
- **WHEN** 평가에서 3번 문항이 틀린다
- **THEN** 리포트에 3번 문항의 질문, 정답 SQL과 결과, 생성 SQL과 결과, 가정, 시도 횟수가 있다
